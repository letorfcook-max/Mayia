# MAYIA ONE — roadmap v2.1–v5.0

Status is source implementation, not production certification. Legacy milestones remain in `src/roadmap.js`.

| Version | Milestone | Status | Actual scope / remaining work |
|---|---|---|---|
| 2.1 | Foundation stabilization | partial | Regression tests, native build workflow and verified downloads retained. Actual OS installer/signing/restart tests outstanding. |
| 2.2 | Intelligence engine | built | Fast/deep/auto preferences, project-specific model IDs and output budgets; not proprietary reasoning or learned routing. |
| 2.3 | Tool engine V2 | partial | Ordered concurrent pure-tool batch and real lifecycle events. Dependency graph, retries and arbitrary custom tool execution not included. |
| 2.4 | Cowork V2 | partial | Supervised planner/reviewer/editor pipeline with actual provider calls, existing task plans and reviewed edits. No autonomous terminal or durable execution checkpoints. |
| 2.5 | Deep research | partial | Real search and Wikipedia article excerpts, source links and public GitHub reader. No general browser crawler or independent fact verification. |
| 2.6 | Memory V2 | partial | Existing opt-in local memory; project can exclude global memory. Semantic retrieval and automatic summaries not implemented. |
| 2.7 | Artifacts | partial | Existing artifact exports and inert source previews. No executable interactive preview or full office rendering. |
| 2.8 | Projects | partial | Persistent project instructions, chat filtering, model preferences; Cowork folder remains manually selected and knowledge library is global. |
| 2.9 | Connect | partial | Public GitHub and Wikipedia readers. Drive, Discord and private OAuth connectors not implemented. |
| 3.0 | Workspace | partial | Mission Control and local persistence; no hosted accounts or synchronization. |
| 3.1 | Computer use | planned | Existing user-approved file operations and external links are not desktop or browser automation. |
| 3.2 | Automations | partial | One-off and recurring notifications while app runs, persisted due times and catch-up. No unattended AI tasks. |
| 3.3 | Plugins | partial | Built-in and user-created instruction workflows; no executable plugin SDK or marketplace. |
| 3.4 | Voice | partial | Existing provider transcription and text-to-speech adapters. No realtime microphone conversation or interruption. |
| 3.5 | Multimodal V2 | partial | Existing image, video, vision, audio adapters; no live provider certification or advanced document understanding. |
| 3.6 | Training Studio | partial | Dataset entry, train/test splits and JSONL exports; existing standalone training scripts. No live training dashboard. |
| 3.7 | MAYIA S1 | partial | Experimental byte-level transformer training and inference scripts. No trained generative weights shipped; not instruction tuned. |
| 3.8 | MAYIA R1 | planned | Multi-role review is not an independently trained reasoning model. |
| 3.9 | Model Hub | partial | Provider model discovery and per-project model routing. No downloads, quantization or hardware benchmarking. |
| 4.0 | MAYIA Intelligence | planned | No independently hosted validated production LLM. |
| 4.1 | API platform | partial | Authenticated loopback chat, model catalog, usage counters and rate/concurrency limits. No hosted developer accounts or billing. |
| 4.2 | Cloud | partial | Encrypted conversation backup for manual transfer; no managed cloud storage, inference or automatic sync. |
| 4.3 | Mobile | partial | Responsive browser companion only; no native iOS or Android binary. |
| 4.4 | Web | partial | Functional local authenticated text chat web companion; no public hosting or desktop feature parity. |
| 4.5 | Teams | partial | Local planning roster with role labels; not collaborative accounts or actual access control. |
| 4.6 | Security | partial | Encrypted exported chats, restricted workspace IPC, preserved file approvals. Local data not encrypted; independent audit outstanding. |
| 4.7 | Enterprise | planned | No organization enforcement, SSO, private enterprise deployments or compliance claims. |
| 4.8 | Marketplace | partial | Local reusable workflow catalog; no public publishing, payments or community marketplace. |
| 4.9 | Optimization | partial | Responsive Mission Control, bounded requests and regression tests. No native performance or accessibility audit. |
| 5.0 | MAYIA ONE | partial | Integrated desktop source preview plus local web/API companion. Full cross-device commercial ecosystem not completed. |
